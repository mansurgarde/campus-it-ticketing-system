# Campus IT Support Ticketing System

**Course:** Software Engineering (SOU30542)  
**Group Name:** CodeCrafters  

## Project Description
A simple web-based ticketing system for Soran University. It helps students and teachers report technical problems (like broken projectors, bad Wi-Fi, or lab computer errors) and helps the IT team track and fix them easily.
